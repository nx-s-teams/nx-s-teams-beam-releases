# Beam — downloads

Beam moves text, screenshots, files and folders between your computers and phone, with private chat and voice calls, through a relay you run yourself. Everything is end-to-end encrypted.

**[Download the latest version](https://github.com/nx-s-teams/nx-s-teams-beam-releases/releases/latest)**

| System | File |
|---|---|
| Windows 10 / 11 | `Beam_<version>_x64-setup.exe` (or `.msi` for managed installs) |
| macOS 11+ (Intel and Apple Silicon) | `Beam_<version>_universal.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |
| Android 8+ (64-bit) | `Beam_<version>_android-arm64.apk` |
| Relay server | `beam-relay-*` for Linux, macOS and Windows |

Installed apps update themselves from this page (from version 1.3). Update files are signed; Beam refuses anything not signed by the project.

`latest.json` on each release is the update feed the apps read. The other `.sig`, `.app.tar.gz` files are update packages, not for manual download.
